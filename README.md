# Employee Management REST API

## Technologies
- Python
- Django
- Django REST Framework
- SQLite
- Git

## Features
- Employee CRUD
- Department CRUD
- Authentication
- Permissions
- Search
- Ordering
- Pagination
- REST APIs

## API Endpoints

GET /api/employees/
POST /api/employees/
PUT /api/employees/{id}/
DELETE /api/employees/{id}/

GET /api/departments/
POST /api/departments/
